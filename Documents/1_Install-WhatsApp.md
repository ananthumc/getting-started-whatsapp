# Install WhatsApp   

The following procedure describes how you can install WhatsApp on your Android phone.

## Prerequisites   

- A stable internet connection.
- An Android phone running OS 6.0 and newer.   
  
To install WhatsApp,   

1.	On your phone, open the Play Store app.
2.	Tap **Search**.
3.	Tap **Search Apps & Games**.
4.	Type “WhatsApp Messenger” and tap the search icon.
5.	From the results page, select WhatsApp Messenger. 
**Note**: Ensure that you select the official application from WhatsApp LLC. 
6.	Tap **Install**. 
Wait until installation is complete.

WhatsApp is now installed on your device. You can open and set up your account.
